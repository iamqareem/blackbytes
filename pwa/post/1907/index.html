LNbits Releases 1.7.0 Urgent Security Update After November 8 Attacks Drain Funds

Web3 · Bitcoin Magazine · 2026-11-10T21:32:45.000Z

LNbits released version 1.7.0 as an urgent security update following November 8 attacks that drained funds from multiple instances, including 2.28 million satoshis from BitTipBot. Operators are instructed to upgrade immediately, rotate credentials, and set up fresh servers if compromised.

Original reporting: Bitcoin Magazine
